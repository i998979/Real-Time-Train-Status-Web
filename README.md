# Real-Time-Train-Status-Web
Real Time Train Status (Web) is the web version of [Real Time Train Status](https://github.com/i998979/Real-Time-Train-Status) on Android that retrieves real-time train location information for East Rail Line, then maps it into a Google Map. Detailed information of the train will be shown by clicking the train icons.


Additionally, TTNT are also embedded to display the estimated arrival time of the trains in the MTR network by clicking the station icons.
